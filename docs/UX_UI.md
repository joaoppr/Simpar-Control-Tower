# UX/UI premium (referência Gartner/McKinsey)

- **Princípios:** headline antes do detalhe, KPIs no topo, um insight por gráfico, ação ao lado do dado (status editável, regra de rateio, exportação).
- **Visual:** fundo claro `#F6F7F9`, cartões brancos com borda fina, tipografia Inter, sidebar azul-marinho `#0B1220`.
- **Paleta:** índigo `#4F46E5` (marca), verde-azulado `#0E9F8E` (economia/positivo), âmbar `#F59E0B` (atenção/potencial), rosa `#E11D48` (risco/desvio). Cores por cloud fixas: AWS âmbar, Azure azul, OCI rosa, GCP verde-azulado, Huawei violeta.
- **Semântica:** variação de custo para cima é ruim (vermelho), economia para cima é boa (verde); chips de esforço/risco/prioridade padronizados.
- **Transparência:** chip permanente "DADOS SIMULADOS", mês de referência no cabeçalho, definições de KPI em tooltip e em `ARCHITECTURE.md`.
- **Acessibilidade:** contraste AA em textos, não depender só da cor (rótulos e ícones), navegação por teclado nos componentes MUI.
